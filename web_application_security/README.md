# web_application_security

## Disclaimer

This module was developed for educational purposes only as part of the Holberton School cybersecurity curriculum.  
All exercises were performed in controlled environments for learning, analysis, and defensive security training.

This module includes the study of common web application vulnerabilities and exploitation techniques strictly within authorized lab environments.

## Description

This directory contains projects focused on web application security, including common vulnerabilities, testing methodologies, and incident response.

It covers both theoretical concepts and practical exercises related to web attacks, vulnerability discovery, and analysis.  
The objective is to understand how web applications can be compromised and how to identify and mitigate these risks.

## Educational Context

This work was completed as part of the Holberton School cybersecurity specialization.  
Each project provides hands-on experience with real-world web security scenarios and tools.

## Projects

### [0x00_web_fundamentals](./0x00_web_fundamentals)

Introduction to web application basics and common attack vectors.

Key elements:
- HTTP concepts
- Host header injection
- cross-site scripting (XSS)
- remote command execution concepts

---

### [0x01_owasp_top_10](./0x01_owasp_top_10)

Study of the most critical web application security risks.

Key elements:
- understanding common vulnerabilities (OWASP Top 10)
- basic exploitation scenarios
- vulnerability identification and analysis

---

### [0x02_burpsuite_fundamentals](./0x02_burpsuite_fundamentals)

Introduction to web application testing using Burp Suite.

Key elements:
- intercepting HTTP requests
- modifying requests and responses
- analyzing application behavior

---

### [0x03_sql_nosql_injection](./0x03_sql_nosql_injection)

Exploration of injection vulnerabilities.

Key elements:
- SQL injection concepts
- NoSQL injection basics
- database enumeration techniques
- input manipulation and testing

---

### [0x04_content_discovery](./0x04_content_discovery)

Discovery of hidden content and resources.

Key elements:
- directory and file discovery
- identification of hidden endpoints
- use of wordlists and enumeration techniques

---

### [0x05_upload_vulnerabilities](./0x05_upload_vulnerabilities)

Analysis of file upload vulnerabilities.

Key elements:
- insecure file upload mechanisms
- bypass techniques
- payload delivery concepts

---

### [0x06_idor](./0x06_idor)

Study of Insecure Direct Object References.

Key elements:
- access control issues

### [0x07_file_inclusion](./0x07_file_inclusion)

Exploration of file inclusion vulnerabilities.

Key elements:
- local file inclusion (LFI)

---

### [0x09_command_injection](./0x09_command_injection)

Key elements:
- command execution through user input

---

### [0x0b_web_application_fast_incident_response](./0x0b_web_application_fast_incident_response)

Introduction to incident detection and response in web environments.

Key elements:
- attack detection

- identification of malicious activity
- basic response strategies

---

### [0x0c_web_application_foresics](./0x0c_web_application_foresics)

Introduction to web application forensics.
