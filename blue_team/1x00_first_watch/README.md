# The First Watch

## Overview

**The First Watch** is the foundation of the **DLH - Cybersecurity Academy Defensive Specialisation**.

Rather than focusing on security tools or technical exploitation, this project introduces the analytical mindset expected from a security professional. Acting as a **Junior Security Analyst**, the objective is to assess an organization's current security posture by identifying its assets, evaluating existing security controls, analyzing risks, and producing professional documentation for executive decision-makers.

This project establishes the foundation upon which the remainder of the Blue Team learning path is built.

---

## Business Scenario

You have just joined **MedDefense Health Systems** as a **Junior Security Analyst**.

Following growing concerns about cybersecurity risks in the healthcare sector, the Board of Directors has requested a complete assessment of the organization's current security posture. Existing documentation is incomplete, previous security efforts were fragmented, and critical information is scattered across multiple sources.

Your mission is to transform incomplete technical information into a structured security assessment that identifies critical assets, evaluates existing controls, highlights security gaps, prioritizes risks, and provides actionable recommendations.

---

## Professional Objectives

Throughout this project, the focus is on developing the ability to:

- Understand an organization's security posture.
- Build and maintain an asset inventory.
- Evaluate asset criticality using the CIA Triad.
- Identify and classify security controls.
- Perform structured gap and risk analyses.
- Prioritize remediation based on business impact.
- Communicate technical findings through professional security documentation.

---

## Assessment Methodology

The project follows a structured security assessment workflow commonly used during consulting engagements and internal security reviews.

```text
Business Context
        │
        ▼
Asset Inventory
        │
        ▼
Criticality Assessment
        │
        ▼
Security Controls Review
        │
        ▼
Gap Analysis
        │
        ▼
Risk Assessment
        │
        ▼
Risk Treatment
        │
        ▼
Executive Reporting
```

This methodology emphasizes understanding the organization before proposing security improvements.

## Professional Relevance

Security teams cannot effectively detect, investigate or respond to incidents without first understanding what they are protecting.

Asset inventories, criticality assessments, security control reviews and risk analyses form the basis of every mature security program. These activities directly support the daily responsibilities of SOC analysts, security consultants, GRC professionals and incident responders by enabling informed decision-making and effective prioritization.

## Key Takeaways

- Build a structured understanding of an organization's security posture.
- Evaluate assets using business and security perspectives.
- Assess existing security controls and identify protection gaps.
- Prioritize remediation according to business risk.
- Produce professional deliverables suitable for executive decision-making.
