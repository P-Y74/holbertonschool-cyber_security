# DLH - Cybersecurity Academy Defensive Specialisation

## Overview

This repository contains my work throughout the **DLH - Cybersecurity Academy Defensive Specialisation** completed as part of the cybersecurity curriculum at **Holberton School**.

The programme is designed to progressively build the technical knowledge and practical skills required for a **Junior SOC Analyst (Level 1)** position. Each project focuses on a specific aspect of defensive security, combining theoretical concepts with hands-on laboratory exercises and real-world investigation methodologies.

The objective is not only to complete the labs, but also to develop a structured approach to security operations, incident detection, threat analysis, digital forensics, and incident response.

---

## Learning Objectives

Throughout this learning path, I progressively develop competencies in:

- Security monitoring and event analysis
- SOC workflows and alert triage
- Threat detection and investigation
- Network and endpoint security
- Windows security
- Cryptography fundamentals
- Threat Intelligence
- Threat Hunting
- Malware analysis fundamentals
- Digital forensics
- Incident response
- Security operations and defensive methodologies
- Identity and access management
- Security awareness and defensive best practices

The overall objective of this specialisation is to acquire the technical foundations expected from a **Blue Team / SOC Analyst Level 1**.

---

## Learning Methodology

Each project follows the same methodology:

1. Study the underlying defensive security concepts.
2. Apply them through practical laboratory exercises.
3. Understand how attackers operate.
4. Learn how defenders detect, investigate and respond.
5. Document the methodology and lessons learned.
6. Relate each exercise to real Security Operations Center (SOC) workflows.

The focus is on understanding **why** defensive techniques are used, not simply completing the exercises.
