# 0x02_forensic_methodologies

## Disclaimer

This project was developed for educational purposes only as part of the Holberton School cybersecurity curriculum.  
All analyses were conducted in controlled environments for learning and investigative training.

## Description

This project introduces the core principles of digital forensics, focusing on investigation methodologies, ethical considerations, and evidence analysis.

Through practical exercises and scenario-based reasoning, it explores how to analyze digital evidence, interpret cybersecurity incidents, and maintain integrity throughout an investigation process.

## Educational Context

This project was completed as part of the Holberton School cybersecurity specialization.  
Its objective is to develop a structured and ethical approach to incident investigation and forensic analysis.

## Learning Objectives

By the end of this project, the following concepts were studied:

- definition and purpose of digital forensics
- importance of ethics in forensic investigations
- maintaining integrity and objectivity during analysis
- ACPO principles for computer forensics
- chain of custody and evidence handling
- stages of the forensic investigation process
- documentation and reporting of findings
- legal considerations in digital investigations
- common forensic methodologies and tools

## Project Tasks

### `0-mystery.txt`
Analysis of image metadata using forensic tools (e.g., `exiftool`) to identify hidden information such as the owner.

---

### `1-location.txt`
Extraction of GPS coordinates from image metadata and identification of the corresponding physical location.

---

### `2-intruder_intent.txt`
Analysis of a network intrusion scenario to determine the attacker’s primary objective.

---

### `3-vulnerability_type.txt`
Identification of the vulnerability exploited in a web application attack scenario.

---

### `4-attack_method.txt`
Determination of the attack method used to compromise a system based on forensic evidence.

---

### `5-ripple_effect.txt`
Analysis of the indirect consequences of a security breach, focusing on business and reputational impact.

Each file contains the result of a specific forensic task or scenario.

