# cybersecurity_basics

## Disclaimer

This module was developed for educational purposes only as part of the Holberton School cybersecurity curriculum.  
All exercises were performed in controlled environments for learning and defensive security training.

## Description

This directory contains introductory projects focused on fundamental cybersecurity concepts.

It covers essential topics such as basic security principles, forensic methodologies, and introductory cryptography.  
The goal of these projects is to build a solid foundation before moving on to more advanced security domains.

## Educational Context

This work was completed as part of the Holberton School cybersecurity specialization.  
Each project is designed to provide hands-on experience with core security concepts through practical exercises and small scripts.

## Projects

### [0x00_introduction_cybersecurity](./0x00_introduction_cybersecurity)

Introduction to basic cybersecurity concepts and simple scripting.

Key elements:
- password generation scripts
- hashing validation (SHA256)
- key generation
- basic system process interaction

---

### [0x02_forensic_methodologies](./0x02_forensic_methodologies)

Introduction to digital forensics and incident analysis.

Key elements:
- analysis of a simulated incident
- identification of attack origin
- understanding attacker intent
- classification of vulnerabilities and attack methods

---

### [0x03_cryptography_basics](./0x03_cryptography_basics)

Introduction to cryptographic concepts and password cracking techniques.

Key elements:
- hash generation (SHA1, SHA256, MD5)
- password hashing
- use of wordlists
- password cracking with tools such as John the Ripper and Hashcat

## Tech Stack

- Bash
- Linux environment
- Basic security tools (hashing utilities, password cracking tools)

## Usage

Each project directory contains its own files and may include a dedicated `README.md` with detailed instructions.

Most scripts can be executed in a Linux environment using:

```bash
chmod +x script.sh
./script.sh
````

## Learning Outcomes

* understanding of basic cybersecurity concepts
* introduction to digital forensics processes
* fundamentals of cryptography and hashing
* basic scripting for security tasks
* first exposure to password cracking methodologies

## Project Status

This module is part of a larger cybersecurity learning path and may be extended with additional exercises over time.
