# Holbertonschool Cyber Security

## Disclaimer

This repository was developed for educational purposes only as part of the Holberton School cybersecurity curriculum.  
All projects, labs, and exercises were performed in controlled environments for learning, analysis, and defensive security training.

This repository does not promote or encourage unauthorized access, exploitation, or misuse of systems, networks, or applications.  
Any use of the information or code outside a legal and authorized context is strictly discouraged and remains the sole responsibility of the user.

## Description

This repository contains projects and practical labs completed as part of the Holberton School cybersecurity specialization.

Its purpose is to document the progression through different cybersecurity domains, including fundamental concepts, Linux security, network security, and web application security.  
Each main directory groups projects by topic, and each project folder contains the related exercises, scripts, notes, or supporting files.

This repository is intended to grow over time as new modules and hands-on projects are completed.

## Educational Context

This work was completed as part of the Holberton School curriculum in cybersecurity.  
The repository reflects a practical, hands-on approach to learning through guided exercises, technical labs, and security-focused projects.

## Repository Structure

The repository is organized by domain.

### [cybersecurity_basics](./cybersecurity_basics)
Introduction to core cybersecurity concepts and foundational methodologies.

Projects included:
- `0x00_introduction_cybersecurity`
- `0x02_forensic_methodologies`
- `0x03_cryptography_basics`

### [linux_security](./linux_security)
Projects focused on Linux system security, permissions, access control, services, and low-level vulnerabilities.

Projects included:
- `0x00_linux_security_basics`
- `0x01_permissions_sguid_sgid`
- `0x02_mandatory_access_control`
- `0x03_protocols_servers`
- `0x04_buffer_overflow`

### [network_security](./network_security)
Projects related to reconnaissance, host discovery, traffic analysis, and port scanning techniques.

Projects included:
- `0x01_passive_reconnaissance`
- `0x02_active_reconnaissance`
- `0x04_nmap_live_hosts_discovery`
- `0x05_wireshark_basics`
- `0x06_nmap_advanced_port_scans`
- `0x07_nmap_post_port_scan_scripting`

### [web_application_security](./web_application_security)
Projects focused on web security fundamentals, common vulnerabilities, testing techniques, and incident response concepts.

Projects included:
- `0x00_web_fundamentals`
- `0x01_owasp_top_10`
- `0x02_burpsuite_fundamentals`
- `0x03_sql_nosql_injection`
- `0x04_content_discovery`
- `0x05_upload_vulnerabilities`
- `0x06_idor`
- `0x07_file_inclusion`
- `0x09_command_injection`
- `0x0b_web_application_fast_incident_response`
- `0x0c_web_application_forensics`

## Learning Objectives

Through these projects, the repository covers topics such as:

- cybersecurity fundamentals
- forensic methodologies
- cryptography basics
- Linux system security
- permissions and access control
- protocols and services
- buffer overflow fundamentals
- passive and active reconnaissance
- network scanning and analysis
- web application vulnerabilities
- secure investigation and incident response concepts
